# Pozostałe biblioteki instrumentów Studio One

Ten spis obejmuje każdy z 17 różnych instrumentów znalezionych przez skaner Studio One. Szczegółowa tabela zawiera nazwy zapisanych na dysku presetów, patchy, banków i pakietów. Nie otwierałem wtyczek ani nie sprawdzałem ich licencji, dlatego obecność pliku nie oznacza, że brzmienie uruchomi się bez błędu.

## Największe zbiory

- Arturia / Analog Lab V: 13333 pozycji
- Surge XT: 4060 pozycji
- Kontakt 8: 335 pozycji
- EZkeys 2: 82 pozycji
- Genuine Sounds Vol. I / GenuineSounds: 44 pozycji
- CollaB3-V2-FREE: 9 pozycji

## Ważne różnice

- Genuine Sounds: 1 bank pobrany, 43 pozycji tylko w katalogu programu.
- Arturia: foldery presetów wielu instrumentów są widoczne, lecz skaner Studio One potwierdza tylko Analog Lab V. To nie dowodzi, że każdy oddzielny syntezator Arturia jest dostępny.
- EZkeys: Session Grand jest bankiem dźwięku; paczki MIDI zawierają frazy i style gry.
- Pianoteq: modele są częścią systemu wtyczki i licencji, a nie katalogami dużych próbek.
- Ivory: skonfigurowana ścieżka biblioteki nie istnieje. Pianoverse: lokalny indeks brzmień jest pusty.
- Wtyczki Martinic, Mojito i część innych mają zawartość wewnętrzną albo brak osobnego katalogu; ich pełny katalog wymaga odczytu z interfejsu lub API producenta.

CSV używa UTF-8 z BOM dla polskich znaków w Excelu. Pierwotny `studio-one-plugins.csv` pozostaje listą samych wtyczek.
